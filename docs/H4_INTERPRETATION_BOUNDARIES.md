# H4 interpretation boundaries

**Frozen alongside `docs/H4_PROTOCOL.md`, before execution.** This
document bounds what any future H4 result — success or failure — can be
read to mean, regardless of outcome.

## What H4 cannot establish, under any result

- A **universal CV-of-CVs constant** — neither the manuscript's `0.610`
  nor this project's own `0.512` (`docs/CV_OF_CV_INTERPRETATION.md`) is
  tested, confirmed, or refuted by H4. H4 concerns *variation* in a
  *contextual* `C_g` across studies, never a single global value.
- A **causal vulnerability mechanism**. H4 is a predictive-association
  test under a frozen observational design, not an experiment; no causal
  claim about *why* meta-variability might relate to future abundance
  change is licensed by any H4 result.
- A **universal ecological threshold** for `C_g` or any related quantity.
- **Real-time forecasting utility** for conservation or monitoring
  practice — H4 tests retrospective, already-collected historical data
  under a frozen protocol, not a deployed forecasting system.
- **Cross-taxon universality** — the corpus is insect abundance records
  only (`docs/DATA_PROVENANCE.md`); nothing here bears on other taxa.
- **Paleontological applicability** — explicitly out of scope
  (`docs/SCOPE_AND_FUTURE_WORK.md`, unchanged).
- **Bioacoustic applicability** — explicitly out of scope
  (`docs/SCOPE_AND_FUTURE_WORK.md`, unchanged).

## If H4 succeeds (SUPPORTED, `docs/H4_PROTOCOL.md` §14)

**The strongest permitted interpretation:**

> Historical contextual meta-variability contains prospective information
> about subsequent abundance change **under the frozen design** — i.e.,
> for the specific `(DataSource_ID, 10-year historical window)` unit,
> `n>=15`-constituent-series adequacy gate, Design-C chronology, and
> conventional-baseline-conditioned comparison frozen in
> `docs/H4_PROTOCOL.md`.

This would **not** license restating the claim as unconditional ("`C_g`
predicts insect decline"), as causal ("tight meta-variability causes
vulnerability"), or as generalizable beyond this corpus, this adequacy
gate, and this specific design, without further, separately-frozen
replication.

## If H4 fails (NOT SUPPORTED or DIRECTIONALLY OPPOSITE)

> CV-of-CVs remains a contextual descriptive statistic without
> demonstrated prospective early-warning value in this dataset.

This is a narrower, more conservative claim than "meta-variability is
never informative anywhere" — it is scoped exactly to what was tested:
this corpus, this adequacy gate (`n>=15`, ~19-20 eligible studies), this
window (10 years, Design C), and this baseline. It does not retroactively
validate or invalidate Round 1's separately-tested, already-closed
individual-series hypotheses.
